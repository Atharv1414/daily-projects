# Passwords and MFA
Use the company password manager. Multi-factor authentication is required on every account, and hardware keys are mandatory for production access.

# Lost devices
Report a lost laptop or phone to the security team within 1 hour by calling extension 4411. The device is then locked and wiped remotely.

# Data classification
Documents are Public, Internal, Confidential or Restricted. Restricted data must never be sent by email or stored on a personal device.
